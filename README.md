# CrystalLight (Светящийся кристалл)

Модификация для Minecraft, добавляющая декоративный 3D-блок «Светящийся кристалл», который служит мощным источником света и издает магические эффекты.

## Совместимость
- Minecraft: 1.21.1
- Fabric Loader: 0.20.1+
- Java: JDK 21

## Установка
1. Установите Fabric Loader для Minecraft 1.21.1.
2. Поместите файл `crystal-light-1.0.0.jar` в папку `mods`.
3. Запустите игру.

## Как получить и использовать
- **Крафт:** 4 осколка аметиста (крестом) + 1 светопыль в центре.
- **Свойства:** Блок излучает максимальный уровень света (15).
- **Дополнительно:** При клике правой кнопкой мыши блок издает звук аметиста и испускает светящиеся частицы.
